# Prototype Product Images

These images are dummy or illustrative assets for the Emhart Glass service-portal prototype. They support visual testing of machine, part, assembly, and technical-drawing workflows.

They are not approved production product photography, engineering references, or safety documentation. Replace or verify them before using the prototype as a production application.

## Categories

- `Machines/`: machine and equipment overview images
- `Parts/`: spare-part and component images
- `Assembley organism/`: assembly and mechanism images
- `technical drawings/`: technical drawing and equipment-layout images

## Intended prototype uses

- Machine selection and equipment overview
- Part search and compatibility results
- Assembly or component detail views
- Technical-document previews
- Empty, loading, and image-error states

Keep image paths category-specific so they can be replaced later without changing the component structure.
