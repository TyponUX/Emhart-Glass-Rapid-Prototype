# IS Machine EF 5 1/2 Overview

- **Document type:** Machine overview
- **Document ID:** EG-MCH-EF512-OV-001
- **Revision:** Rev C
- **Applies to:** IS Machine EF 5 1/2
- **Status:** Current

## Overview

The IS Machine EF 5 1/2 is a forming machine line used for high-volume glass production. This overview identifies the primary machine areas used when searching for parts, documentation, and service support.

## Main areas

- Blank side forming equipment
- Blow side forming equipment
- Baffle mechanism
- Blowhead and blowhead arm
- Lubrication system
- Section frame
- Conveyor and ware handling
- Controls and safety systems

## Service guidance

Before ordering a replacement part, confirm the machine type, section number, equipment revision, and current configuration. Use the installed-base record to verify compatibility.
