# Service Portal Prototype

A Vite prototype using React and shadcn/ui.

## Setup

Run the shadcn initialization command from this project root, then install dependencies with pnpm.

## Ownership rules

- Product and UX knowledge belongs in `docs/`.
- Images and documents belong in `assets/`.
- Application mock data belongs in `src/data/`.
- Application code belongs in `src/`.
- External documentation links belong in `docs/sources/`.
